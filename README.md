# Everyday Things, Two Lines

Two-line explanation of an everyday thing (a toaster) for a 10-year-old,
built for the make.fun bounty "Everyday Things, Two Lines, Longer Run".

Run it with `python3 main.py` — it writes `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

Made with [make.fun](https://make.fun/r/06fpcnax).
